# ADR 0006: Monero via client-side wallet (monero-ts)

- **Status:** Proposed — M5 spike
- **Spec:** D2
- **Date:** 2026-09-24

## Context

Running monero-wallet-rpc server-side would make Monero custodial and/or leak view keys.

## Decision

Client-side wallet; backend proxies a restricted monerod. Spike must show acceptable mobile sync performance.

Pending spike result.
